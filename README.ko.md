## 할 수 있는 일

- **공식 숫자를 버튼 하나로 (1.2).** 터미널에서 Claude Code 2.1.80 이상을 Pro/Max로 쓰면, Claude Code가 상태줄에 넘겨주는 공식 남은 %를 연결해요. 끄면 원래 상태줄로 돌아가요
- **색만 보면 돼요.** 5시간·최근 7일 사용량을 초록(여유)·노랑(주의)·빨강(곧 다 씀)으로
- **실제 한도를 배워요.** 한 번 한도에 걸리면 그때까지 쓴 양으로 남은 양을 더 정확히 추정하고, 지금 속도면 언제 다 쓰는지 알려 줘요
- **여러 AI를 탭으로.** Codex·Gemini CLI·Antigravity·Cursor(활동량 추정)를 쓰면 탭이 저절로 생겨요
- **새는 사용량을 찾아요.** 너무 길어진 대화를 찾고, 새 대화로 넘길 요약을 복사해 줘요
- **어떤 AI든 추가.** JSON 기록을 남기는 AI면 기록 폴더를 고르고, 한도를 요청 횟수나 토큰으로, 하루·5시간·주·월 주기로 직접 정해요. 탭이 많으면 옆으로 넘겨 봐요
- 더블클릭으로 한 줄 보기, 어두운·밝은 테마, 글자 크기 4단계, 한국어·English·日本語·简体中文

## `/usage`가 있는데 왜 필요하죠?

정확한 숫자는 공식 `/usage`가 기준입니다. 다만 확인하려면 하던 일을 멈추고 직접 쳐야 하고, 물어봐야만 알려 줍니다. 게이지는 Claude가 일하는 동안에도 화면에 떠 있고, 평소보다 빨리 쓰면 노랗게 바뀌고, 지금 속도면 언제쯤 다 쓰는지 알려 줍니다. 한도에 **걸린 뒤가 아니라 걸리기 전에** 알 수 있어요. Codex·Gemini CLI·Antigravity·Cursor(활동량 추정)도 한곳에서 봅니다.

## 개인정보

- PC에 남는 AI 도구 기록만 읽어요(Claude Code: `~/.claude/projects`)
- 로그인 정보·토큰은 읽지 않아요. 대화 내용은 PC 밖으로 나가지 않아요(인터넷은 라이선스 확인에만)
- 연결하지 않으면 남은 양은 **추정치**예요. 연결하면 Claude Code가 상태줄에 주는 숫자를 쓰고, 이때도 로그인 정보는 읽지 않아요
